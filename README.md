# Fullstack-система заказа мебели для компании "Alfurat"

Коммерческий проект под ключ: веб-интерфейс для каталога мебели, серверная часть (API) для обработки заявок и встроенная админ-панель для управления заказами.

## 🛠 Технологический стек
* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+), Адаптивная верстка.
* **Backend:** Node.js, REST API.
* **Деплой / Хостинг:** Netlify (Frontend CDN), Render (Backend Hosting), GitHub (Контроль версий).

---

## 🚀 Реализованный функционал

1. **Раздельная архитектура (Headless):** Фронтенд и Бэкенд развернуты независимо друг от друга, что обеспечивает высокую скорость загрузки интерфейса и безопасность серверных данных.
2. **Интерактивный каталог:** Адаптивный веб-интерфейс, который идеально отображается на смартфонах, планшетах и ПК.
3. **Обработка заказов на Node.js:** Написан сервер, который принимает POST-запросы с формами заказов, валидирует данные и отправляет их в панель управления.
4. **Админ-панель:** Выделенное пространство внутри системы для менеджеров компании, где хранятся, фильтруются и обрабатываются все поступающие заявки.
